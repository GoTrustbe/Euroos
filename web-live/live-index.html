Try it live

A real EuroOS desktop, in your browser.

No download, no install. Enter your e-mail and we boot you a private, throw-away EuroOS virtual machine you drive straight from this page over a secure connection. It is the same from-scratch, sovereign OS you can download, its own kernel, filesystem, network stack, capability security and desktop, with no Linux or BSD underneath.

A session lasts 30 minutes, then it is wiped. One session at a time.
  • ●Private & throw-away. Your own virtual machine; every change is discarded when the session ends.
  • ●No guest network. The VM has no path to the internet, it is a sealed sandbox.
  • ●We store only your e-mail so we can see who is trying EuroOS, nothing from inside the session.

Runs on our own server, no third-party cloud. Because it runs under full software emulation (no hardware acceleration on the host), the desktop is usable but not as snappy as a local install, for full speed, download the image and boot it with virtualization enabled. Capacity is limited; if all slots are busy, try again in a few minutes.
